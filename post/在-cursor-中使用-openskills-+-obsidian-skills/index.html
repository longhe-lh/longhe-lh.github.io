🧠 在 Cursor 中使用 OpenSkills + Obsidian Skills（完整实战指南）

目标：在 Cursor 中使用 Anthropic 的 Skills 体系（通过 OpenSkills），并结合 Obsidian Skills 提升生产力。

✨ 一、什么是 OpenSkills？

OpenSkills = Claude Skills 的通用加载器

它的作用是：

  • 把 Anthropic 的 SKILL.md 变成通用格式
  • 生成 AGENTS.md（供 AI 读取）
  • 让 Cursor / Codex / Aider 等工具都能用 Skills

🧠 核心理解（一句话）

1

Skill = 一段“专家级 Prompt 模板”

👉 OpenSkills 做的事情：

1

读取 SKILL.md → 输出 Prompt → 你喂给 AI

🚀 二、环境准备

1️⃣ 安装要求

  • Node.js >= 20.6
  • Git

2️⃣ 安装 OpenSkills（无需全局安装）

直接用：

1

npx openskills

📦 三、安装 Skills

✅ 1. 安装官方 Skills（Anthropic）

1

npx openskills install anthropics/skills --universal

✅ 2. 安装 Obsidian Skills（推荐）

1

npx openskills install kepano/obsidian-skills --universal

📁 安装后目录结构

1
2
3
4

6

  skills/
    obsidian-markdown/
      SKILL.md
    json-canvas/
    obsidian-cli/

🔧 四、生成 AGENTS.md（关键步骤）

1

npx openskills sync

生成：

1

AGENTS.md

👉 作用：

  • 告诉 AI 当前有哪些 skills
  • 统一技能描述格式（XML）

📚 八、Obsidian Skills 说明

Skill 功能
obsidian-markdown 写 Obsidian Markdown
obsidian-bases 类似数据库（Notion风格）
