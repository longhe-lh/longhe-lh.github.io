🧠 在 Cursor 中使用 OpenSkills + Obsidian Skills（完整实战指南）

目标：在 Cursor 中使用 Anthropic Skills 体系（通过 OpenSkills），并结合 Obsidian Skills 提升知识生产效率。

✨ 一、什么是 OpenSkills？

OpenSkills = Skills 的通用加载与适配层

它的核心作用是：

  • 将 Anthropic 的 SKILL.md 转换为标准格式
  • 生成统一的 AGENTS.md
  • 让不同 AI 工具（Cursor / Aider / Codex）可以理解 Skills

🧠 核心理解（一句话）

1
2

Skill = 一段“专家级 Prompt 模板”
OpenSkills = Skill 的组织与分发工具

🚀 二、Cursor 中 Skills 的使用方式

⚠️ 两种使用模式（非常重要）

✅ 1. 隐式使用（推荐，现代方式）

在 Cursor 中，你不需要手动读取 Skill，可以直接：

1

使用 xlsx skills 帮我生成20条登录测试用例

或：

1

用 obsidian-markdown skills 帮我生成一篇笔记

👉 模型会：

  • 自动识别任务
  • 自动匹配对应 skill
  • 自动应用 skill 的规则

✅ 2. 显式使用（高级控制）

在以下情况建议使用：

  • 你想精确控制 prompt
  • Skill 复杂或效果不稳定
  • 你需要调试输出

步骤：

1

npx openskills read <skill-name>

然后粘贴到 Cursor：

1
2
3
4

（粘贴 Skill）

请帮我完成以下任务：
xxx

🧠 结论

1
2

日常使用 → 直接说人话即可（推荐）
调试 / 精细控制 → 手动加载 Skill

📦 三、环境准备

1️⃣ 安装要求

  • Node.js >= 20.6
  • Git

2️⃣ 安装 OpenSkills

1

npx openskills

📥 四、安装 Skills

✅ 官方 Skills

1

npx openskills install anthropics/skills --universal

✅ Obsidian Skills（推荐）

1

npx openskills install kepano/obsidian-skills --universal

🔧 五、生成 AGENTS.md

1

npx openskills sync

生成：

1

👉 作用：

  • 让 AI 知道有哪些 Skills
  • 提供统一上下文
  • 提升自动调用能力（关键）
