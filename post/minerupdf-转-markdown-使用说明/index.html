📄 MinerU：PDF 转 Markdown 使用说明

本文档介绍如何使用 MinerU 将 PDF 文件转换为 Markdown（.md），涵盖**单文件转换、批量转换以及性能优化（加速）**等内容，帮助你在不同场景下获得最佳效果。

🧩 一、环境要求

确保已完成以下配置：

  • ✅ 已安装 MinerU（当前版本：2.7.6）
  • ✅ Python 环境正常（建议使用 Conda）
  • ✅ GPU 可用（如需加速）
  • ✅ （可选）已配置远程推理服务（用于 http-client 模式）

测试命令：

1

mineru --version

🚀 二、基本命令格式

MinerU 使用统一 CLI 命令：

1

mineru -p <输入路径> -o <输出目录> [可选参数]

📘 三、单个 PDF 转 Markdown

✅ 使用指令

1

mineru -p "test.pdf" -o "output_dir"

📌 示例

1

mineru -p "D:\papers\example.pdf" -o "D:\output"

📦 输出结果

在 output_dir 中通常会生成：

1
2
3

example.md          ✅ Markdown 文件（目标）
example.json        📊 结构化解析结果
images/             🖼️ 图片资源

📚 四、批量转换（整个文件夹）

✅ 使用指令

1

mineru -p "PDF文件夹路径" -o "输出目录"

📌 示例

1
2

mineru -p "C:\Users\helon\Desktop\Software Security\ref papers" \
       -o "D:\mineru\batch_trans_res"

📌 功能说明

  • ✔ 自动处理目录中的 PDF 文件
  • ✔ 支持多文件批量转换
  • ⚠️ 是否递归子目录取决于版本（建议实际测试）

⚡ 五、加速与性能优化（重点）

MinerU 的性能优化核心在于：

✅ 后端（backend） + 硬件（device） + 解析策略（method）

🚀 1. GPU 加速（强烈推荐）

1

-d cuda

指定 GPU：

1

-d cuda:0

👉 适用于：

  • OCR 任务
  • 模型推理
  • 大规模批量处理

🚀 2. 推荐高性能命令（本地）

1
2
3
4
5

mineru -p "输入路径" \
       -o "输出目录" \
       -b hybrid-auto-engine \
       -d cuda \
       -m auto

👉 特点：

  • ✅ 精度高
  • ✅ 速度快
  • ✅ 自动策略选择

🚀 3. 使用远程加速（极致性能）

1
2
3
4

mineru -p "输入路径" \
       -o "输出目录" \
       -b hybrid-http-client \
       -u http://127.0.0.1:30000

👉 特点：

  • 本地只做轻量任务
  • 重计算交给远程服务
  • 速度取决于服务器性能

🚀 4. 纯文本 PDF 极速模式

1

-m txt

👉 适用于：

  • 论文（可复制文本）
  • 电子书
  • 非扫描 PDF

👉 速度最快（推荐优先尝试）

🚀 5. 限制处理范围（加速）

1

-s 0 -e 10

👉 只处理前 10 页

🚀 6. 关闭不必要功能

1
2

-f False   # 关闭公式识别
-t False   # 关闭表格识别

👉 可显著提升速度（特别是 OCR 场景）

📌 六、参数说明（核心理解）

参数 作用 说明
-p 输入路径 文件或目录（必填）
-o 输出路径 结果存放位置（必填）
-b backend 选择处理架构（非常重要）
-d device 控制 CPU / GPU
-m method 解析方式（txt / ocr / auto）
-l lang 语言（提升 OCR 精度）
-u server_url 远程推理地址
-s/-e 页范围 控制处理页数

🧠 七、解析模式选择（重要）

模式 说明 适用场景
auto 自动判断（推荐） 通用
txt 文本提取 纯文本 PDF（最快）
ocr OCR识别 扫描件 PDF

⚠️ 八、常见误区（重要）

❗ 1. -b ≠ CPU / GPU

  • -b：控制处理架构（算法）
  • -d：控制计算设备（CPU/GPU）

❗ 2. 默认并不一定是最优

建议根据场景选择：

  • 快速：

    1

    -m txt -d cuda

  • 高精度：

    1

    -b hybrid-auto-engine -d cuda

❗ 3. 路径必须加引号（Windows）

1

"D:\My Papers\paper.pdf"

🔍 九、结果验证

检查输出目录：

输出目录/

├── example.json
├── images/

🧪 十、常见问题

❌ Missing option ‘-p’

👉 原因：未指定输入路径 👉 解决：

1

mineru -p input.pdf -o output_dir

❌ GPU 未生效

👉 检查：

1

-d cuda

并确认：

  • CUDA 已安装
  • GPU 可用

❌ 速度慢

👉 优化建议：

  • 使用 -m txt
  • 使用 GPU：-d cuda
  • 使用 hybrid backend
  • 限制页数：-s/-e

❌ 子目录未处理

👉 可能原因：

  • 版本不支持递归

👉 解决：

  • 编写脚本递归调用
  • 或手动分目录处理

🎯 十一、总结（推荐组合）

🚀 单文件最快

1

mineru -p file.pdf -o out -m txt -d cuda

🚀 高精度推荐

1

mineru -p file.pdf -o out -b hybrid-auto-engine -d cuda

🚀 远程高性能

1

mineru -p file.pdf -o out -b hybrid-http-client -u http://server:port

🚀 批量处理

1

mineru -p input_dir -o output_dir -d cuda
