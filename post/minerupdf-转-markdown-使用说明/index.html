📄 MinerU：PDF 转 Markdown 使用说明

本文档介绍如何使用 MinerU 将 PDF 文件转换为 Markdown（.md），包括单文件转换和批量转换两种场景。

🧩 一、环境要求

确保已完成以下配置：

  • ✅ 已安装 MinerU（当前版本：2.7.6）
  • ✅ Python 环境正常（建议 Conda）
  • ✅ GPU 可用（如需加速）

测试命令：

1

mineru --version

🚀 二、基本命令格式

MinerU 当前版本使用 单层 CLI 命令：

1

mineru -p <输入路径> -o <输出目录> [可选参数]

📘 三、单个 PDF 转 Markdown

✅ 使用指令

1

mineru -p "test.pdf" -o "output_dir"

📌 示例

1

mineru -p "D:\papers\example.pdf" -o "D:\output"

📦 输出结果

在 output_dir 中生成：

1
2
3

example.md          ✅ Markdown文件（目标）
example.json        （结构化数据）
images/             （图片资源）

📚 四、批量转换（整个文件夹）

✅ 使用指令

1

mineru -p "PDF文件夹路径" -o "输出目录"

📌 示例

1
2

mineru -p "C:\Users\helon\Desktop\Software Security\ref papers" \
       -o "D:\mineru\batch_trans_res"

📌 功能说明

  • ✔ 自动处理目录中的 PDF 文件
  • ✔ 支持多文件批量转换
  • ⚠️ 是否递归子目录取决于版本（建议测试）

⚡ 五、推荐参数（强烈建议）

✅ 使用 GPU 加速

1

-d cuda

✅ 完整推荐命令

1
2
3
4

mineru -p "输入目录" \
       -o "输出目录" \
       -d cuda \
       -m auto

📌 参数说明

参数 说明
-p 输入 PDF 文件或目录（必填）
-o 输出目录（必填）
-d 设备（cuda / cpu）
-m 解析方式（auto / txt / ocr）

🧠 六、解析模式选择（重要）

模式 适用场景
auto 自动判断（推荐）
txt 文本型 PDF（论文、报告，速度快）
ocr 扫描版 PDF（图片型）

⚠️ 七、注意事项

❗ 1. 默认不只输出 Markdown

MinerU 会生成：

  • .md（目标文件）
  • .json
  • images/

👉 如只需要 Markdown，请自行筛选 .md 文件

❗ 2. 空间路径需加引号

例如：

1

"C:\Users\xxx\My Papers"

🔍 八、结果验证

转换完成后，检查：

1
2

输出目录/
├── xxx.md   ✅ 是否存在

🧪 九、常见问题

❌ 报错：Missing option ‘-p’

👉 原因：未使用 -p 参数 👉 解决：

1

mineru -p input.pdf -o output_dir

❌ GPU 未生效

👉 检查是否添加：

1

-d cuda

❌ 子目录未处理

👉 当前版本可能不递归 👉 解决：

  • 手动分层处理
  • 或使用脚本递归调用

🎯 十、总结

功能 命令
单个 PDF mineru -p file.pdf -o out
批量目录 mineru -p dir -o out
GPU 加速 -d cuda
推荐模式 -m auto
