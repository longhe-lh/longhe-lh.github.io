创建和管理会话

1
2
3
4

tmux new -s myjob          # 新建会话
tmux ls                    # 查看所有会话
tmux attach -t myjob       # 重新连接会话
tmux kill-session -t myjob # 关闭会话

会话内常用操作

  • 退出但让程序继续跑（detach） Ctrl + B 然后按 D

  • 新建窗口 Ctrl + B 然后按 C

  • 切换窗口 Ctrl + B 然后按 N (next) 或 P (previous)

  • 分屏 水平分屏：Ctrl + B 然后 % 垂直分屏：Ctrl + B 然后 "

  • 关闭当前 pane/窗口 在 pane 中输入 exit 或 Ctrl + D
