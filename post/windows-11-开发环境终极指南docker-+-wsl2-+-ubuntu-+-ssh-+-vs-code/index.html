Windows 11 开发环境终极指南：Docker + WSL2 + Ubuntu + SSH + VS Code

本教程旨在帮助开发者在 Windows 11 上构建一个高效、隔离且不占用 C 盘空间的 Linux 开发环境。

🚀 Step 1: 下载 Docker Desktop

前往 Docker 官方下载页，下载 Windows 版本安装包：Download for Windows - AMD64。

  • 官方网站：https://www.docker.com/products/docker-desktop/

🛠️ Step 2: 深度自定义安装（防爆 C 盘）

⚠️ 注意： 不要直接双击安装！默认安装会将 Docker 存放在 C 盘，长期使用会占用数十 GB 空间。

假设你的安装包路径为 D:\softwares\docker_desktop\installer.exe，计划安装到 D:\docker_desktop，请执行以下步骤：

  1. 按下 Win + R，输入 cmd 并回车。

  2. 输入并运行以下指令：

    1

    start /w "" "D:\softwares\docker_desktop\installer.exe" install --installation-dir=D:\docker_desktop

  3. 安装选项： 过程中务必勾选 √ Use WSL2 instead of Hyper-V (recommended)。

  4. 安装完成后点击 Close。

🐧 Step 3: 安装 & 升级 WSL2

Docker 运行依赖高版本的 WSL 内核。如果提示版本过低，请手动更新：

  • 官方下载链接： https://github.com/microsoft/WSL/releases
  • 安装方式： 下载 .msi 或 .appxbundle 后直接双击，按照提示完成。

💾 Step 4: 修改磁盘存储位置 & WSL 融合

为了彻底释放 C 盘压力，需要修改 Docker 的数据存储路径：

  1. 修改存储路径： 打开 Docker Desktop，点击 ⚙设置 -> Resources -> Advanced，将 Disk image location 修改为非 C 盘目录（如 D:\Docker\vmdk）。
  2. 开启 WSL 融合： 点击 ⚙设置 -> Resources -> WSL integration，找到 Enable integration with additional distros，勾选 Ubuntu。

📦 Step 5: 手动部署 Ubuntu（自定义位置）

为了避免从商店安装默认占用 C 盘，我们采取“手动解压部署”法：

  1. 下载地址： https://link.zhihu.com/?target=http%3A//jump.bdimg.com/safecheck/index%3Furl%3DrN3wPs8te/rTq%2Ba8Lbj5Zm7XLknhXoUwF9xVFQXr9y0%2Bwbj616rLo1Kf3e5NOZrWPJkIR6KldcsRMijU04BOJwifk9jM5J%2BLwovZZFqqRJYcfVMreZWVs3GyqzCHBh1ZjDzt6OBjc6Wp/LHHvi17sDRxU17r5hqHl0iEkJ7c4Vu6eNXNRRxxJhi6jDdKnmSfOtTUEiFP9PVO0wxW5fVdNZfYhc2r0ea%2B8%2BiIBQW4BVt2Pah4egTNMg%3D%3D
  2. 解压步骤：
    • 得到 Ubuntu2004-220404.appxbundle 后，改后缀为 .zip 并解压。
    • 在文件夹内找到 Ubuntu_2004.4.2.0_x64.appx，再次改后缀为 .zip 并解压。
  3. 安装与初始化：
    • 将最终解压的文件夹移动到目标磁盘（如 D:\WSL\Ubuntu）。
    • 双击 ubuntu.exe 启动安装，设置用户名和密码。
  4. 文件交互技巧：
    • 在 WSL 中，Windows 磁盘挂载在 /mnt/ 下。
    • 例子： 进入 D 盘的 test 文件夹：cd /mnt/d/test/。

🌐 Step 6: 局域网 SSH 远程访问（镜像网络模式）

💡 新版特性： 如果你使用的是 Windows 11 (23H2 及以上)，镜像网络 (Mirrored mode) 是最佳实践。

1. 配置镜像网络

① 按下 Win + R，输入 %UserProfile% 并回车。

② 新建或编辑 .wslconfig 文件，添加：

1
2
3
4
5
6
7

[wsl2]
# 开启镜像网络模式
networkingMode=mirrored
# 允许 WSL2 里的服务绑定到所有本地 IP
localhostForwarding=true
# （可选）开启防火墙集成，让 Windows 防火墙规则自动应用到 WSL2
firewall=true

③ 重启 WSL： 在 PowerShell 运行 wsl --shutdown。

2. 配置SSH

在Ubuntu终端内执行：

① 安装

1
2

sudo apt update
sudo apt install openssh-server

② 修改配置：使用 sudo vim /etc/ssh/sshd_config ，确保以下几项：

  • Port 22 (或者你喜欢的自定义端口)
  • ListenAddress 0.0.0.0
  • PasswordAuthentication yes (允许密码登录)

③ 重启：`sudo service ssh restart

3. Windows 放行端口

在管理员模式的 PowerShell 中运行：

1

netsh advfirewall firewall add rule name="WSL2-SSH" dir=in action=allow protocol=TCP localport=22

💻 Step 7: VS Code 远程开发最佳实践

  1. 本地安装： Remote - SSH 插件。

  2. 连接： 点击左下角蓝图标 >< -> Connect to Host...。

  3. 地址： 输入 ssh 用户名@Windows的局域网IP。

  • 连接后，你可以在 VS Code 底部看到 SSH: [IP地址]，此时的操作环境完全在 WSL 内部。

🌍 Step 8: 超出局域网？（外网访问）

  • 简单方案： 使用11Nat。在 Windows 内网端登录后，在外网段登录并配置端口映射即可。
  • 硬核方案： 如果你有公网 IP，在路由器上做 端口映射 (Port Forwarding)，将外部端口指向你 Windows 的局域网 IP。
